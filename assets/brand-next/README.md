# Logo files for the next APK build

These pictures are ready but NOT used yet. A phone only gets a new app icon,
first flash screen and notification icon from a new APK, not from an
`eas update`.

At the next APK build, app.json will point to them:

| File | Used for |
|---|---|
| icon.png | App icon (1024 x 1024) |
| android-icon-foreground.png | Android adaptive icon, logo layer |
| android-icon-background.png | Android adaptive icon, green layer (#0b4a2f) |
| android-icon-monochrome.png | Android 13+ themed icon |
| splash-icon.png | First flash screen logo (background #0b4a2f) |
| notification-icon.png | Small white icon in the notification bar |
| favicon.png | Web version |
